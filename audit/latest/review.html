Next upgrades, in priority order

  1. Offer a Reading mode. Keep the tunnel as the default, but let visitors choose larger, stationary sections. The existing reduced-motion fallback provides a useful foundation. The captured desktop build and phone matrix illustrate how projection can make text and targets smaller than their CSS sizes. Test actual projected touch targets, keyboard progression, zoom, and screen-reader order; selected-state and focus styling alone do not establish accessibility compliance.
  2. Make builds evidence-led. Separate interactive concept demos from shipped projects. Add the problem, your role, what the demo supports, and a measured outcome when one exists. Existing descriptions refer to real-time collaboration, AI, payments, and enterprise integrations; these claims need to be checked against each demo's actual functionality. No outcomes were invented in this update.
  3. Make navigation and metadata agree. The active world changes during the combined journey while the URL and route metadata remain tied to the entry route. Define shareable chapter anchors and predictable refresh/back behavior. Work's metadata still uses the earlier “multilingual web development” positioning and references /images/web-og.jpg, which is absent from public assets. Align titles, social images, and multilingual metadata with the current portfolio.
  4. Consolidate motion and styling. There are multiple motion components and layers of global CSS overrides. The transparent-panel issue came from this cascade. Establish a small set of shared HUD, content-panel, spacing, and typography rules; remove legacy components only after checking imports. Profile the shared scene on slower phones before adding more effects.
  5. Finish the operational path. The contact endpoint stores submissions in the database; it does not send an email notification. Decide how new inquiries should be surfaced, add submission abuse protection, and verify failure recovery with the real backend. Also make the Between unlock requirements and its 72-hour access window clearer to visitors.
